Set up browser-wide Tars

Chrome requires one-time microphone permission. Audio is sent only while you hold Control.

The frontend address is loaded from apps/extension/.env and is never collected on this page.

  1. Set CTRLTEACH_FRONTEND_URL and reload the extension whenever its origin changes.
  2. Enable the microphone below, then return to Ctrl+Teach and turn on Tars.
  3. On any regular web page, hold Control to talk and release to send the visible tab context.
