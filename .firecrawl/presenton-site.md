## Frequently asked  questions

What is Presenton and how is it different from typical slide tools?

Presenton is an open-source AI presentation generator that stands out from typical slide tools through its complete customization capabilities using custom templates and built-in presentation automation features.

Who is Presenton for—developers embedding slides or teams creating them in the UI?

Presenton serves both developers and designers. It includes a prompt-based designer interface that allows users to edit templates through prompts, though it doesn't include the elaborate editing tools that designers might typically expect. For developers, it provides an API for creating and editing presentations programmatically.

What file formats do you output (PPTX, PDF) and are decks fully editable afterward?

Presentations can be exported to both PPTX and PDF formats. The PPTX format maintains full editability with standard tools like Microsoft PowerPoint and Google Slides.

How do I bring my own templates and brand assets?

You can use the built-in AI template converter to transform your existing PPTX or PDF files into reusable templates. A complete overview guide is available at [https://docs.presenton.ai/create-presentation-template-with-ai](https://docs.presenton.ai/create-presentation-template-with-ai). Developers can also create custom templates with code using the guide at [https://docs.presenton.ai/creating-custom-presentation-templates](https://docs.presenton.ai/creating-custom-presentation-templates).

Do you support charts, tables, images, and data-driven components?

Yes, charts, tables, and images are supported, but they need to be specified during the template creation process.

Can I control fonts, colors, and layout rules globally?

Yes, Presenton supports global theming, allowing you to create a brand theme and apply it consistently across all presentations.

Is my data used to train models?

No, your data is not used to train any models.

How do I contact for custom deployment support?

Please content suraj@presenton.ai for any custom deployments or integrations.
